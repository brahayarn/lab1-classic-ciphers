# Лабораторна робота 1 — шифри заміни та перестановки

Консольна програма, яка зашифровує й розшифровує український текст чотирма навчальними
алгоритмами: простою підстановкою за ключовим словом, шифром Віженера, блоковою і
вертикальною перестановкою.

> Класичні шифри зберігають статистику тексту і не забезпечують цілісності.
> Не використовуйте їх для паролів, персональних чи службових даних.

## Вимоги

- Python 3.8+ (перевірено на CPython 3.9.6, macOS 15 arm64)
- Зовнішніх залежностей немає — лише стандартна бібліотека (`unicodedata`, `argparse`, `unittest`)

## Запуск

Усі команди виконуються з кореня проєкту.

```bash
python3 -m classic_ciphers --help
python3 -m classic_ciphers rules                       # правила підготовки тексту

# Контрольні вектори з методички
python3 -m classic_ciphers encrypt -c substitution --table ЯЮЬЩШЧЦХФУТСРПОНМЛКЙЇІИЗЖЄЕДҐГВБА -t "СЛАВА УКРАЇНІ"
python3 -m classic_ciphers encrypt -c vigenere -k КЛЮЧ -t "СЛАВА УКРАЇНІ"
python3 -m classic_ciphers encrypt -c block -k "3 2 5 1 4" --mode letters -t "СЛАВА УКРАЇНІ"
python3 -m classic_ciphers encrypt -c columnar -k "3 1 4 2" -t "КРИПТОГРАФІЯ"

# Розшифрування
python3 -m classic_ciphers decrypt -c vigenere -k КЛЮЧ -t "ВЬЮЩК ДЇККЧЛД"
python3 -m classic_ciphers decrypt -c columnar -k "3 1 4 2" --pad 0 -t "ИГІКТАПРЯРОФ"

# Робота з UTF-8 файлами
python3 -m classic_ciphers encrypt -c columnar -k "4 1 3 7 2 6 5" -i samples/message.txt -o cipher.txt
#   stderr: Додано службових символів: 4. Для розшифрування вкажіть --pad 4.
python3 -m classic_ciphers decrypt -c columnar -k "4 1 3 7 2 6 5" --pad 4 -i cipher.txt -o plain.txt

# Ручне введення: без -t та -i текст читається зі стандартного вводу (завершити Ctrl-D)
python3 -m classic_ciphers encrypt -c substitution -k ЗАХИСТ

# Додатково: частоти, індекс збігів, оцінка довжини ключа Віженера
python3 -m classic_ciphers analyze -i experiments/results/vigenere.enc.txt
```

Параметри `encrypt` / `decrypt`:

| Параметр | Призначення |
|---|---|
| `-c, --cipher` | `substitution`, `vigenere`, `block`, `columnar` |
| `-k, --key` | ключове слово (substitution, vigenere) або перестановка `"3 2 5 1 4"` / `3,2,5,1,4` |
| `--table` | substitution: готова таблиця B із 33 літер замість ключового слова |
| `--mode` | block, columnar: `preserve` (типово, зворотний) або `letters` |
| `--pad-char` | columnar encrypt: службова літера доповнення (типово `Х`) |
| `--pad` | columnar decrypt: кількість доданих символів, яку повідомив encrypt |
| `-t` / `-i` | текст у командному рядку / вхідний файл |
| `-o` | вихідний файл (записується атомарно; при помилці не створюється) |

Коди завершення: `0` — успіх, `1` — некоректний ключ, текст або файл (повідомлення
`Помилка: …` у stderr, без трасування), `2` — неправильні аргументи командного рядка.

## Демонстрація: від розділу звіту до команди

Усі команди з кореня проєкту. Таблиця показує, де у звіті про це йдеться, який файл за це
відповідає і що запустити, щоб побачити результат.

| Розділ звіту | Де в коді | Що запустити |
|---|---|---|
| 2–3. Теорія і специфікація | `classic_ciphers/text.py` | `python3 -m classic_ciphers rules` |
| 4. Перевірка ключів | `substitution.py`, `vigenere.py`, `permutation.py`, `columnar.py` | блок «Помилки» нижче |
| 5. Проста підстановка | `substitution.py` | перший рядок блоку «Контрольні вектори» |
| 5. Віженер | `vigenere.py` (`_shift`) | другий рядок блоку |
| 5. Блокова перестановка | `block.py` (`_apply`), `permutation.py` (`invert`) | третій рядок блоку |
| 5. Вертикальна перестановка | `columnar.py` | четвертий рядок блоку, потім блок «Доповнення» |
| 6. Контрольні вектори | усі модулі | блок «Контрольні вектори» або `python3 experiments/run_experiment.py` |
| 7. Тестування | `tests/` | `python3 -m unittest -v` |
| 8. Власний текст | `samples/message.txt`, `experiments/results/` | блок «Файли» |
| 9. Частотний аналіз | `analysis.py` | `python3 -m classic_ciphers analyze -i experiments/results/vigenere.enc.txt` |

**Контрольні вектори** (результат у коментарі):

```bash
python3 -m classic_ciphers encrypt -c substitution --table ЯЮЬЩШЧЦХФУТСРПОНМЛКЙЇІИЗЖЄЕДҐГВБА -t "СЛАВА УКРАЇНІ"  # ІНЯЬЯ ЗОЇЯРЛС
python3 -m classic_ciphers encrypt -c vigenere -k КЛЮЧ -t "СЛАВА УКРАЇНІ"                                    # ВЬЮЩК ДЇККЧЛД
python3 -m classic_ciphers encrypt -c block -k "3 2 5 1 4" --mode letters -t "СЛАВА УКРАЇНІ"                 # АЛАСВРКЇУАНІ
python3 -m classic_ciphers encrypt -c columnar -k "3 1 4 2" -t КРИПТОГРАФІЯ                                  # ИГІКТАПРЯРОФ
python3 -m classic_ciphers decrypt -c vigenere -k КЛЮЧ -t "ВЬЮЩК ДЇККЧЛД"                                    # СЛАВА УКРАЇНІ
python3 -m classic_ciphers decrypt -c block -k "3 2 5 1 4" --mode letters -t АЛАСВРКЇУАНІ                    # СЛАВАУКРАЇНІ
python3 -m classic_ciphers decrypt -c columnar -k "3 1 4 2" --pad 0 -t ИГІКТАПРЯРОФ                         # КРИПТОГРАФІЯ
```

**Доповнення** у вертикальній перестановці (довжина не кратна числу стовпців):

```bash
python3 -m classic_ciphers encrypt -c columnar -k "3 1 4 2" -t КРИПТОГРАФ              # ИГХКТАПРХРОФ, «Додано службових символів: 2»
python3 -m classic_ciphers decrypt -c columnar -k "3 1 4 2" --pad 2 -t ИГХКТАПРХРОФ    # КРИПТОГРАФ
```

**Помилки** (повідомлення «Помилка: …», код завершення 1, без трасування):

```bash
python3 -m classic_ciphers encrypt -c block -k "1 1 2" -t А; echo $?          # повтор у перестановці
python3 -m classic_ciphers encrypt -c block -k "1 5 2" -t А; echo $?          # число поза діапазоном
python3 -m classic_ciphers encrypt -c vigenere -k "" -t А; echo $?            # порожній ключ
python3 -m classic_ciphers encrypt -c vigenere -k КЛЮЧ -t Hello; echo $?      # латиниця у тексті
python3 -m classic_ciphers decrypt -c columnar -k "3 1 4 2" --pad 4 -t ИГІКТАПРЯРОФ; echo $?   # доповнення 0..3
```

**Файли** (власний текст на 482 літери):

```bash
python3 -m classic_ciphers encrypt -c vigenere -k ЗАХИСТ -i samples/message.txt -o cipher.txt
python3 -m classic_ciphers decrypt -c vigenere -k ЗАХИСТ -i cipher.txt
```

## Тести

```bash
python3 -m unittest            # 88 тестів
python3 -m unittest -v         # з назвами тестів
python3 experiments/run_experiment.py   # відтворюваний експеримент → experiments/results/
```

Групи тестів (`tests/`): контрольні вектори, зворотність (12 фіксованих повідомлень і
генеративні тести з фіксованим зерном, по 300 випадкових ключів і текстів на алгоритм),
українські літери Ґ Є І Ї та NFC, граничні довжини, форматування, негативні сценарії
ключів, UTF-8 файли, доповнення вертикальної перестановки, CLI, частотний аналіз.

## Специфікація обробки тексту

| Аспект | Правило |
|---|---|
| Алфавіт | `АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ`, m = 33, індекси 0..32 |
| Кодування | файли — UTF-8; BOM на вході ігнорується; переноси `\n` і `\r\n` зберігаються як є |
| Нормалізація | NFC → верхній регістр → NFC |
| Регістр | результат завжди у верхньому регістрі |
| Допустимі символи | літери алфавіту, пробіли, табуляція, переноси рядків, цифри, розділові знаки, апострофи `' ʼ ’`, `№`, математичні та валютні знаки |
| Недопустимі | латиниця, літери інших алфавітів (Ы, Ё, Ъ, Э), емодзі, окремі комбіновані знаки — помилка з номером позиції |
| Підстановки | символи поза алфавітом залишаються на місці й не просувають ключ Віженера |
| Перестановки, `preserve` | переставляється весь підготовлений текст, включно з пробілами й переносами |
| Перестановки, `letters` | спершу вилучається все, крім літер; незворотний щодо форматування |
| Блокова | неповний останній блок не змінюється |
| Вертикальна | останній рядок доповнюється службовою літерою; її кількість (0..k−1) потрібна для розшифрування, вилучається рівно стільки символів |

Розшифрування повертає **підготовлений** текст: `D(E(x)) = prepare(x)`, тобто малі літери
стають великими. Для точної зворотності форматування використовуйте файли (`-i`/`-o`):
під час виведення на екран програма додає завершальний перенос рядка, якщо його немає.

## Структура

```
classic_ciphers/
  text.py          алфавіт, нормалізація, перевірка символів, режими перестановок
  substitution.py  проста підстановка: побудова і перевірка таблиці
  vigenere.py      шифр Віженера
  permutation.py   розбір, перевірка й обернення перестановок
  block.py         блокова перестановка
  columnar.py      вертикальна перестановка з доповненням
  analysis.py      частоти, індекс збігів, оцінка довжини ключа (додаткове завдання)
  fileio.py        читання/атомарний запис UTF-8
  errors.py        класи передбачуваних помилок
  cli.py           командний рядок (єдиний модуль, що знає про введення/виведення)
tests/             автоматизовані тести (unittest)
samples/           власний текст (482 літери)
experiments/       скрипт відтворюваного експерименту та його результати
docs/              звіт
```
